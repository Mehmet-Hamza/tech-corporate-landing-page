# 🌐 X-Teknoloji - Landing Page & Login UI

Modern, şık ve tüm cihazlarla tam uyumlu (responsive) kurumsal web sitesi ön yüz tasarımı.

## 🚀 Özellikler

- **Tam Responsive Yapı:** Masaüstü, tablet ve mobil ekranlara uyumlu Flexbox ve Media Query mimarisi.
- **Dinamik Tipografi:** CSS `clamp()` fonksiyonu ile ekran boyutuna göre otomatik ölçeklenen fontlar.
- **Tasarım Bütünlüğü:** Kurumsal marka kimliğini koruyan responsive Landing Page ve Login/Register ekranı.
- **Sayfa Yönlendirmeleri:** `index.html` ve `login.html` arasında entegre form ve yönlendirme akışı.

## 🛠️ Teknolojiler

- HTML5
- CSS3 (Flexbox, CSS Variables, Media Queries)
- FontAwesome & Google Fonts (Montserrat)
